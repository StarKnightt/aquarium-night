# Aquarium at night

A realistic Three.js home aquarium — all assets generated in code (r180 + Vite).

**Controls:** tap the water to feed · tap the glass · drag to look around · sound toggle (bottom-right)

## Run locally

```bash
npm install
npm run dev      # http://localhost:5199
npm run build
npm run preview
```

## Redeploy

Redeploys run automatically on push to `main` via GitHub Actions:

```bash
git add -A
git commit -m "your message"
git push
```

Live site: https://starknightt.github.io/aquarium-night/
